# 本文題名とページ見出し

PDFの上端12%・下端12%に同じ文字列が全ページで見つかる場合、Wordに出力する書式を比較します。同じ書式が2ページ以上で反復する出現だけをheader/footerへ移します。例えば初ページが14.35ptの題名、後続ページが8.97ptの見出しなら、初ページの題名は編集可能な本文に残り、後続ページには各ページの小さい見出しを設定します。

比較には実際に出力するrunのfont、文字サイズ、太字・斜体、色、下線、文字幅・間隔と段落の整列を使います。同じ書式の隣接runは比較時だけまとめ、PDFの描画命令の分割の違いを吸収します。原本文字列やfont programを書き換えません。本文から除く対象は選ばれた出現そのものです。

見出しが異なるページは個別のsectionを使い、二段組のページ内sectionにも同ページの参照を渡します。前ページに見出しがあっても、次ページが本文題名だけなら空のpartで継承を解除します。段落のsectPrに属するテキスト見出しもZIP部品へ保存し、10番目以降のrelationshipも番号に対応するpartへ解決します。

見出しの左端・中心・右端は原本ページの座標を使い、実際のsection左右余白からの符号つきindentへ変換します。本文より左にある見出しも本文余白へ押し込めず、中央寄せの書き込み幅を縮めません。非有限・ページ外の座標や未確認のページ幅、未対応の余白設定は既存の配置へ戻します。

共有可能性の比較には自動生成される段落IDを使いません。同じ書式・位置・ページ幅なら見出しを共有でき、同じ文字列でも中心位置が違うページは個別のsectionを使います。比較のためだけに一時段落を生成する副作用も避けています。

この補完対象は変換器が生成するテキストのページ見出しです。段落sectionに画像やリンクを含む見出しを手動で追加した場合は、未対応のrelationshipを黙って落とさず梱包エラーにします。

## 検証と制限

自作データで本文題名の保持、二段組、見出し継承の解除、12ページの部品対応を回帰検証しています。プロパティテストは4〜24ページ・一段/二段を変え、header/footerの書式と本文の所属を実際のDOCXの参照から確認します。

配置の回帰テストは本文余白96ptに対する左右・中央の見出しを上下両方で確認します。別のプロパティテストではページ幅・左右余白・行位置を変え、Wordの領域から独立に復元したanchorが原本座標と0.5twip以内で一致し、中央行の書き込み幅が保たれることを検証します。

[EfficientNetの原本](https://proceedings.mlr.press/v97/tan19a/tan19a.pdf)は以前収集した同一PDFを使い、変換前に保存した59ファイルとTable1の正解データを保持しています。観測済み不具合の修正であり、未観測のholdout評価ではありません。nativeでは初ページの題名を本文に戻し、後続9ページの見出しを約9ptに保持しました。復元済み12画像のpayload・anchorと、題名以外の本文text nodeは以前の結果と一致しています。

その後の水平配置の検証では、原本見出しの中心に対するずれがnativeで約35.07ptから0.0331pt、pure/WASMで約35.09ptから0.0410ptになりました。native20ページ・pure20ページの比較では、見出しの帯を除く全pixelが直前の結果と一致しています。見出しの文字幅やfont自体の再現を証明する検査ではありません。[配置の検証と追加資料の失敗](../corpus/validation-page-chrome-origin.json)も参照してください。

これはページ全体の再現精度の合格を意味しません。この論文は原本10ページに対してLibreOffice出力が20ページのままで、表構造、図形、font fallback、本文・caption・labelや文字の幅に課題が残っています。Microsoft Wordでの表示も未検証です。文字列が全ページに揃わない見出し、単独ページだけの見出し、交互に変わる文字列や複数行の見出しを一般的に認識する機能ではありません。

コード固定後に追加した[Batch Normalizationの原本](https://proceedings.mlr.press/v37/ioffe15.html)は、初ページだけ異なる題名を持つ9ページの資料です。全ページと元fontを確認し、図4の表の数値32個を変換前に固定しました。nativeは部分clipの重なりに関する安全検査で拒否し、pureは19件の品質診断を出してstrict変換を拒否します。pureの通常変換は18ページとなり、数値32個は9行の本文として残るものの6列のWord表にはならず、8個の短い見出しが本文に残り、数式には59個の置換文字があります。いずれも修正前の基準版と同じ結果で、追加資料の精度合格を意味しません。最初に手で転記したモデル名1件の空白誤りは原本を再確認した訂正記録を別に残し、元の正解ファイルと数値32個は変更していません。
