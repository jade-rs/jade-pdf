# 本文題名とページ見出し

PDFの上端12%・下端12%に同じ文字列が全ページで見つかる場合、Wordに出力する書式を比較します。同じ書式が2ページ以上で反復する出現だけをheader/footerへ移します。例えば初ページが14.35ptの題名、後続ページが8.97ptの見出しなら、初ページの題名は編集可能な本文に残り、後続ページには各ページの小さい見出しを設定します。

比較には実際に出力するrunのfont、文字サイズ、太字・斜体、色、下線、文字幅・間隔と段落の整列を使います。同じ書式の隣接runは比較時だけまとめ、PDFの描画命令の分割の違いを吸収します。原本文字列やfont programを書き換えません。本文から除く対象は選ばれた出現そのものです。

見出しが異なるページは個別のsectionを使い、二段組のページ内sectionにも同ページの参照を渡します。前ページに見出しがあっても、次ページが本文題名だけなら空のpartで継承を解除します。段落のsectPrに属するテキスト見出しもZIP部品へ保存し、10番目以降のrelationshipも番号に対応するpartへ解決します。

この補完対象は変換器が生成するテキストのページ見出しです。段落sectionに画像やリンクを含む見出しを手動で追加した場合は、未対応のrelationshipを黙って落とさず梱包エラーにします。

## 検証と制限

自作データで本文題名の保持、二段組、見出し継承の解除、12ページの部品対応を回帰検証しています。プロパティテストは4〜24ページ・一段/二段を変え、header/footerの書式と本文の所属を実際のDOCXの参照から確認します。

[EfficientNetの原本](https://proceedings.mlr.press/v97/tan19a/tan19a.pdf)は以前収集した同一PDFを使い、変換前に保存した59ファイルとTable1の正解データを保持しています。観測済み不具合の修正であり、未観測のholdout評価ではありません。nativeでは初ページの題名を本文に戻し、後続9ページの見出しを約9ptに保持しました。復元済み12画像のpayload・anchorと、題名以外の本文text nodeは以前の結果と一致しています。

これはページ全体の再現精度の合格を意味しません。この論文は原本10ページに対してLibreOffice出力が20ページのままで、表構造、図形、font fallback、本文・caption・labelや見出しの横位置に課題が残っています。Microsoft Wordでの表示も未検証です。文字列が全ページに揃わない見出し、単独ページだけの見出し、交互に変わる文字列や複数行の見出しを一般的に認識する機能ではありません。
