# 官報の公開ガイドで確認した表・背景・数字の保持

[官報発行サイトの「公開対象の記事について」](https://www.kanpo.go.jp/pdf/target_article.pdf)を、最初の変換前に原本2ページすべて目視し、52条件を固定した。2026年11月26日取得、202,447 bytes、SHA-256 `70d9b514d2d24aa18d4d6707b3ed91b990d11ae477086f430010cf3123400d77`。空passwordで開け、印刷・copyを許可する暗号化PDFである。個別の公告や個人記録を含まない一般ガイドであり、[利用条件](https://www.kanpo.go.jp/guidance.html)を確認した。外部PDF・font・logoはtracked fixtureへ追加しない。

出典：官報発行サイト「公開対象の記事について」。加工したローカル評価結果であり、公式掲載物ではない。PDL1.0の対象外表示と第三者の権利に関する条件も維持し、fontやlogoの再配布許諾を推定しない。

## 原本に基づく三つの修正

背景scannerは`W/W*`を見つけると原本の背景を未確認にしていた。単独の軸平行`re`矩形を確認できるclipだけを受け入れ、既存clipとの積で実際に塗られる範囲を保存する。clipはpathを終える時点で確定し、その前の塗りへ遡って適用しない。`q/Q`でclip状態を復元し、空の積を再び無限範囲へ戻さない。三角形・曲線・複合pathなどは従来どおり未確認とする。文字の前後関係、不透明性、色、予算、全セル被覆の条件を保ち、部分塗りを全セルの背景へ広げない。

完全な原本罫線gridに、折り返した本文の文字開始位置を追加して3列を4列へ変更する問題もあった。内側の縦罫線があり、各行帯のgridを確認できる場合は、実在する罫線を列の根拠とする。外枠だけで内部罫線がない場合は、既存の文字列推定を使う。資料名や語句、固定した列数で分岐しない。

一・二ページの裸の数字は、連番の証拠が不足してfooterを生成しない一方で、旧来のページ番号除去で本文から消えていた。この範囲では原文の数字を本文へ残す。新たなfooter役割を推定しない。三ページ以上の既存連番照合、装飾付きラベル、回転本文の既存判定はそのまま使う。公開field・CLI・依存は追加していない。

## 残る不一致

表示された文字は1,589→1,599で、原本1,622文字のうち23文字がセル内で切れる。四つの斜線と曲線の括弧が欠け、節見出しに余分な下線が付く。数字1/2は編集・表示できるが代替fontと丸めたsizeは原本と異なり、二ページ目の位置も下へずれる。原本のfooter条件は未達のままである。

原本のFontDescriptorはすべて400で、ページ内の`Tr2`の存在だけで本文全体を太字にしない。今回、原本をcondensed textとみなす変更も加えていない。既存のMS-PGothic代替字幅補正が、一部の原本位置付きセルの出力経路に適用されていないことを確認したが、これは次の独立した回帰と描画で検証する。

暗号化された元PDFは書き換えない。native通常は成功するが、strictは`UnsupportedCurvedPath`で拒否する。両browserは通常・strictとも`UnsupportedEncryption`で拒否する。browser上でこの官報原本の背景・表を再現できたとは主張しない。

82個の原本・gold・初回・保留manifest、延べ70,300ファイルを再照合した。他資料の変更していない描画はruntimeごとのRAW一致で継承し、労働力調査36/57、CPI26/107の未達を残す。集計処理で親評価のkeyを誤読した一度の失敗は保存し、作成済みの集計を再照合して新しい処理から再開した。runtimeや描画は再実行していない。

kanpo-parser/kanpo-docxの原本grid・セル所有・書式を区別する考え方は[固定した参照記録](source_typography_and_table_opening.md#参照)を参照。custom licenseのコード・依存を取り込まず、既存parserとWord builderへ独立実装した。
