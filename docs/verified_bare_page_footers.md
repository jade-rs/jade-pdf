# 原本で照合できる裸のページ番号

原本下側の裸の数字が旧本文フィルタで失われる場合に、全ページの原本条件が揃う組だけを literal Word footer として復元する。既存の反復 footer と装飾付きページ番号が優先される。

対象は3ページ以上で、全ページに同じ寸法・書式・下端からの距離・中央位置を持つASCII整数が一つずつあり、その値が連続する場合だけである。ページ寸法の差は0.1pt以下、baseline距離と中央からの差は1pt以下。下側12%に収まり、原本の中央から最大emまたは2pt以内の文字だけを調べる。桁数が変わっても実際のWord run書式で照合する。

PDFiumの水平glyph角度、またはネイティブ解析のupright文字行列から確認できたbaselineとem矩形が必要である。向きが不明な文字、画像・graphicと重なる文字、複数の数字候補、欠番、書式や位置の不一致、回転ページ、内部空白や符号、整数加算のoverflowでは復元しない。2ページ以下は旧挙動を維持する。原本にない番号や動的なPAGE fieldを生成しない。拒否対照は「footerを発明しない」検査であり、旧経路で失われる数字の全体再現を承認するものではない。

この実装は、kanpo-parser/kanpo-docxの表・書式保持を調査した継続作業の一部である。原本要素と照合して編集可能なWord構造へ戻す方針を使い、参照元のコードや依存を取り込んでいない。

空白で3語以上かつ小文字を含み、幅8em以上の散文が左右それぞれ8行以上ある場合は、表への割当て前の原本文字行で確認し、文書全体の組を復元対象から外す。BERTブラウザdefaultでfooter追加だけにより既存27ページが28ページへ増えた研究段階を保存し、実資料を評価したうえで条件を狭めた。文字数・OOXML本文の一致だけでは改ページの正しさを保証できない。

## 検証と限界

固定した原本・goldを変更せず、Census NST-EST2025の既知資料でページ番号1/2/3/4を復元した。97行のvariable/description表、4ページの対応、全7,981非空白文字を保持する。原本130項目の追試は128成功・2失敗。見出しの下線・配置と全体の見た目（本文空白、代替fontのglyph/baselineを含む）が未達のため、文書全体やproduction readyとは判定しない。最初の未見資料評価4成功・126失敗は保存したままであり、追試を未見精度として数えない。

所有対照は連番4ページ、桁変化3ページ、欠番4ページ、2ページと密な散文段組4ページの計5資料・17原本ページ。単体APIで既知の条件であり未見資料ではない。CLI/browserで使う前に全原本ページを確認しgoldを固定した。

TDDは公開byte APIと方向不明のIR対照でRedを保存し、8公開テスト（24例PBTを含む）、IR対照、既存装飾付きfooter3テストを通した。default全体検査は2,558成功・0失敗・42ignored、148 groups。対象sourceを固定したnative/WASM/Chromium/WebKitの結果と、変更のあった出力の全ページレビューはvalidation ledgerに記録する。

CLI186回、Chromium/WebKit計388回を実行した。既存544件の成功・拒否条件を保ち、538件の成果物はbyte単位で一致する。変更した6件はCensusのfooterであり、生成IDとfooter参照・距離を除いた本文OOXMLは同じである。[検証台帳](../corpus/validation-verified-bare-page-footers.json)に固定hashと残課題を記録した。

密な散文の追加対照は、原本にない罫線付き表が残るためsource table goldを不合格として保持する。footer非発明の検査とは別に記録し、goldの緩和や文書全体の受け入れは行わない。

scoped native/browser比較は104組がRAW byte一致し、4組（2 positive sourceのstrict×2 engine）は生成段落IDだけ異なる。全package partを比較し、その7ページのrender RGBが直接確認済みnativeと完全一致することを検査した。段落IDの決定性は主張しない。

未対応資料や既存のfont置換・一般的な改ページ・図形・日本語資料の残課題は引き続き別に検証する。component検証の通過を文書全体の受け入れに置き換えない。
