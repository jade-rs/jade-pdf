# TJで離して描かれた数値欄の保持

PDFの一つの`TJ`命令が複数の数値欄を描く場合、文字列を一つの矩形へ結合すると、異なる値が同じWordセルへ入る。実測した文字幅と描画位置を使い、離れた数値を独立した要素として表へ渡す。表外の本文では値の間の語間も保持する。

## 適用条件

同じtext開始と同じ`TJ`内にあり、両方の文字幅を測定でき、正立baselineと1em以上の正の描画間隔を確認できる場合に限る。対象は32byte以内の符号付き十進数で、桁区切りと小数点の構文を検査する。散文、和文、不正な数値、科学表記、回転・傾斜した描画、未知の文字幅、小さいtrackingはこの分離の根拠にしない。一度でも推定幅を含めて結合した要素も対象外とする。

既存の文字幅推定やType1の位置付き要素の経路は維持する。列幅の等分やfontの圧縮でセルを推測しない。数値列の半emの桁差では、座標の浮動小数点丸めを1ULP以内、かつemの0.01%以内で扱い、元の右端anchorを保持する。本文runの結合では、同じsize・baselineの数値間にある0.2em以上の語間を残す。添字や既存の空白を重複して処理しない。

## 表の数値列と本文の段間

表の数値間隔を二段本文の根拠へ数えると、上の表や図を含む段組みができ、captionの欠落や余計なページが生じる。数値同士の隙間は段間の曖昧さを検査する候補には残すが、新しい本文の縦範囲を広げる根拠にはしない。

既存の段組み判定が成立する場合は、その分割範囲を保つ。既存判定が成立せず、数値の根拠を除いて本文を復元する場合は、四行以上の本文で確認した縦範囲の中だけに狭い段間を適用する。範囲内を横断する行は拒否する。行全体が数値の場合は狭い段間で切らず、散文行の年・巻号で終わる参考文献は既存の別カラムに保つ。従来の広い間隔による分割は変更しない。

## 原本との照合

評価原本は[統計局の全国CPI資料](https://www.stat.go.jp/data/cpi/sokuhou/tsuki/pdf/zenkoku.pdf)。2026年10月分の固定取得物は437,176byte、12ページ、SHA-256は`aaee8d56c3b468808a4c5e6001a6e84b89345133eab78f9982b94883f0b695e6`。動的URLの最新版を同じ原本と扱わない。[先行する原本確認と利用条件](source_table_text_ownership.md)および107項目のgoldを変更していない。

原本の11行について、七つずつの数値が別々の編集可能なセルへ入ることを確認した。全22,665非空白文字と15表は保持する。初回の14成功・93未達/未検証、親の15成功・92未達/未検証に対し、既知資料への追試はnative・Chromium・WebKitとも26成功・81未達/未検証となった。未見文書の精度率ではない。

CPIは依然として12ページから16ページへ増える。物理ページ対応、結合見出し、六つのgraphの線、字体・強調・logoのdecodeは未達または未検証である。FontDescriptorのweight400を、Gothicという名前だけで太字と扱わない。

## 検証範囲

producerは`e9c49b9b2ce5432cd911ceebfc2f2ae49ecaad82`。TDDのRedを保存し、公開byte API、数値構文、未知の幅、丸め境界、語間、散文との混在、段間の曖昧さ、本文外の図表、座標の倍率・移動・行順を検査した。Rust 1.93.1でCIと同じdefault検証を実行し、2,611成功・失敗0・42ignored、153グループとなった。fmtとfixture混入検査も通過した。

native192通りは168成功・24拒否、ブラウザ各200通りは171成功・29拒否。計592通りの結果は親の期待値と一致し、573出力はRAW byteが一致した。変更した19出力の非空白文字の個数、画像byte、表数、太字・斜体・font・色・sizeの文字単位のmultisetを照合した。CPIの文字順は元のセル対応へ分離した結果として変わる。下線とEfficientNetの添字一文字のbaseline位置は完全一致とはしていない。

両ブラウザの200出力と100inspectionは一致した。EfficientNetはnative・browserとも19ページ、BERTは27、BatchNormは18、CPIは16。EfficientNetの変更した四つのページ対を個別確認し、残る34ページは親とRGBが一致した。9ページ目の本文間隔は変わる。図の線、数式、脚注と段間の衝突、原本10ページからの再配置は依然として未達である。

他の変更出力は、確認済み成果物とのRAW一致、または画像relationship IDのみの対応と全XML・画像の同一性から描画確認を引き継いだ。NAOJの5ページと1ページ抜粋は親とRGB一致を保つが、元の2,152文字という基準に対して2,153文字となる未達は変更しない。Census・SF94・三段本文の既存の未達も残す。

原本・gold・親および却下した試作を含む45,911ファイルを再hashした。表や図の改ページに回帰のあった試作は保留記録として残し、承認済みの比較基準にはしない。[検証台帳](../corpus/validation-source-numeric-tj-positions.json)はこの限定した機能の記録であり、文書全体のproduction readinessの達成ではない。

kanpo-parser/kanpo-docxから参考にした文字と表の所有対応、通常体と太字を区別する考え方は[固定コミットの参照記録](source_typography_and_table_opening.md#参照)を参照。参照元のコード・依存を追加せず、既存のIRとbuilderへ独立に実装した。公開API・CLI・依存は変更せず、外部のPDF・font・logoはtracked fixtureに追加しない。
