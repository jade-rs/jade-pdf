# 原本の各辺の線幅とWord表の行境界

表のすべての辺を最大線幅へ置換せず、原本の各辺の区間と幅をWordセルへ個別に渡す。確認済みの物理gridと原本文字・fontを使える、非結合の閉じた表に適用する。別のfontや部分罫線・結合表をこの処理のために作り直さない。

## 公開IRの値の変更

`ParsedGraphicElement`の型とfieldは増やさない。同一直線でも太さが異なる区間を最大幅へ統一せず、隣接する物理的な空隙も残す。同じ軸・ページ・固定座標・線幅で実際に接するか重なる区間だけをparserで結合する。`graphics_count`は増え得る。整数投影の最大1ptのgap許容と最大線幅への結合はWordの互換topology viewに残し、原本の連続inkの証拠として使わない。

前段の[小数罫線のガイド](fractional_table_rules.md)で記録したparserの1pt gap結合は、この追試では物理区間の保持へ変更する。呼出元が旧整数キーや旧結合を必要とする場合は、量子化・結合を用途に応じて明示する。描画の幅や連続性を確認するときは、原本区間の情報を捨てない。

## 辺全体の確認とWordへの保存

原本境界が一意で、セル本文とfontが照合済みの`source_rule_grid`を使う。物理row/columnとモデルの対応が一致し、全セルが非結合で四辺を持つ場合だけ対象にする。罫線の索引は同じページの該当grid軸と交差範囲へ限定し、無関係なgraphicsや一律幅の表のためにモデルを複製しない。

同じ辺に異なるWord幅が対応する場合は精密化しない。各辺を実在する原本線分で連続して覆う必要がある。f32の座標差に使うepsilonは最大0.001pt、かつ辺長の1/4以下とする。角では、その中心を通る実在する直交線がある場合だけ、直交線の原本ink半幅まで端点の接続を認める。1pt以内にあるだけの空隙を連続した細い実線へ置き換えない。

Wordセルの上・左・下・右へ個別の幅を保持し、対角線の保存や既存の代表幅を上書きしない。幅は既存のWord border変換と同じ1/8pt単位、2から96の範囲を使う。原本0.6ptは0.625pt、1.32ptは1.375ptとなる。原本0.12ptは0.25ptとなり、厳密な再現とは扱わない。確認できない辺は従来の代表幅を継承する。

## 行境界と文字容量

水平線を細くすると、検証環境の描画では内罫線の中心が半線幅差だけ移った。原本の29.5/30.5ptの二行でも、外枠1.5pt・内罫線0.5ptならWordの名目行高を30/30ptとすることで中心間隔を保つ。全高を増やさず、境界ごとの補正を累積丸めして隣接差だけを各行へ加える。Wordの1/8pt幅単位を`sz`とすると補正twipは`round((代表sz - 境界sz) * 1.25)`である。

全列で同じ実効境界幅を持ち、上下の実際の外枠が従来の代表幅と一致し、各行高を正に保てる場合だけ補正する。表外側に存在しない隣接セルを仮定して、外枠幅の違いを隠さない。原本文字が補正後の行へ収まるか、既存段落と同じ累積行間の丸めで確認する。失敗した場合は水平線の精密化と行高補正を戻す。適用できる変更が残らなければ、新しい表モデルを採用しない。
