# 表外本文の所有座標を一度だけ決める

罫線表へ文字を割り当てたときのY反転の判断を、本文から表内文字を取り除くときにも使う。従来はセルへの割当で原本の下端原点を確認していても、後段で表がpage上半分にあることから反転候補を再推定していた。そのため、表の鏡像領域にある別の本文・見出し・注記が、表にも本文にも入らず消えていた。

推定表の内部情報に座標判断を保持し、親table wrapperにも引き継ぐ。既存の上端原点補正が実際に必要だった表は同じ判断を保つ。独立した閉じた枠や、原本runから作る反復列表は原本座標のまま扱う。セルの推定、font復号、公開API、依存は変更しない。

## 検証記録の訂正と残課題

最初のrender一覧はファイル名順だったため、配列indexと物理page番号を取り違えた記録があった。元の初回記録は変更せず、実際のPNGファイル名から番号を取り直し、必要な差分ページを追加で個別確認した。実際の初回browser差分は1・3・4・15ページ、CPI修正版の差分は3・4・5・16ページである。追試auditに引き継がれた「Native16ページすべて直接確認」の表現も、変更4ページの直接確認と残り12ページのRAW継承へ訂正した。

CPIは依然16ページで、数値セル・結合見出し・graph線・font/強調・logo decodeに問題が残る。文書全体のproduction readinessは未達である。今回の検証は、解析済みの表外本文を二度目のY反転推定で失わないという限定したcomponentの範囲である。
