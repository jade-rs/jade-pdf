# 白い塗りと横並びの原本表

PDFの細い白い塗りを黒罫線へ変換すると、離れた二つの表がつながり、セルの所有関係を失う。確認できた白い描画命令だけを罫線候補から除外し、同じ上端にある独立した原本表を、別々の編集可能なWord表として配置する。

## 白い塗りを除外する条件

対象はDeviceGray・DeviceRGB・DeviceCMYKの白い非stroke塗りである。有限の成分値を検査し、PDFの成分範囲へのclipも扱う。`q/Q`で塗り色を復元し、stroke色と非stroke色を混同しない。未知の色命令は白の根拠を解除する。

所属ページのResourcesが完全かつ一意で、Device色の既定置換がなく、全`gs`が既知で、非strokeの不透明度1・通常合成・soft maskなしと確認できる場合に限る。印刷設定の`BG2/UCR2 /Default`などは検査する。未知の効果、転写関数、透明な塗り、未知・重複・曖昧なResourceは従来の経路へ残す。

Contents配列は、境界へ空白を挿入せず連続した字句として検証する。確認済みの白い塗り命令の位置を、従来の罫線走査の候補位置と照合する。境界をまたぐ`Q`が黒を復元した場合や、文字列・配列内に似た命令がある場合に黒線を消さない。検証済みの展開metadataを再利用するため、圧縮オブジェクト内のResourcesとExtGStateも扱う。索引・位置配列・保存状態は既存の資源予算へ計上し、不足時は部分的な証明や抽出結果を返さない。

これは白い塗りから偽の黒線を作らないための処理である。既存の黒線を白が覆う場合のocclusion、一般の色付き図形、graphの意味認識を実装したものではない。

## 独立した表の位置と本文の高さ

複数行・複数列を持ち、原本の四辺を実罫線で確認できる、横に離れた連続表だけを対象にする。外辺が分割されていても、整数化誤差一単位の範囲で線分の被覆が連続するか検査する。間隔の大きい欠損を補って外枠を推測しない。

上端の差は0.25point以内とし、ページ内の有限座標に限る。回転ページ、段組み、入れ子の表、重なる表、表の帯に別の本文・画像・表がある場合は従来のflowを保つ。別の左端と共通の上端を、ページ原点から測った浮動表の位置へ渡す。セル・行列・結合・文字列は維持する。

浮動表を追加するだけでは後続の本文や表が横へ回り込むため、一組分の原本高を本文に一度だけ確保する。表ごとの高さを縦に加算せず、後続の見出しを表の下へ置く。Wordの位置指定は[OOXMLの浮動表の定義](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.wordprocessing.tablepositionproperties?view=openxml-3.0.1)に従う。

## 原本を先に固定した追試

原本は[統計局の労働力調査参考資料](https://www.stat.go.jp/data/roudou/sokuhou/tsuki/pdf/recent_trends.pdf)。固定取得物は2026年9月分、171,159byte、2ページ、SHA-256は`2b9acc64f36b88d49763696a06c8bce0785a2e1bab05b66675ae529d29077f10`。動的URLの最新版を同じ原本と扱わない。出典・[利用条件](https://www.stat.go.jp/info/riyou.html)・機密情報の有無・全2ページを確認し、変換前に57項目のgoldを登録した。PDL1.0の出典表示・加工表示を記録し、logoはその適用外としてlocal評価に限定する。外部PDF・font・logoはtracked fixtureへ追加しない。

初回はnative・Chromium・WebKitとも20成功・37未達/未検証だった。文字1,164個の個数は一致したが、二つの実表は本文へ崩れ、graphは9行96列の誤った表になり、原本2ページがWord4ページになった。この初回結果とgoldは変更していない。

追試では白い橋渡し一本だけを除き、原本1ページ目の39罫線を38罫線にした。他の罫線・文字IRは一致する。年平均の4列3行、月次の4列4行、結合した見出しと年、元の列に対応する七つの数値セルを復元した。数値を下線へ変えず、黒い辺をセル罫線として保持する。表を縦に積む途中版は5ページになったため保留し、横並び配置と一組分の高さの確保で4ページへ戻した。

同じ57項目の追試は各31成功・26未達/未検証である。未見文書の精度率ではない。原本2ページからWord4ページへの増加、比較見出しとgraphの誤った表、青・黄の塗り、字体、明示的なfill-and-stroke強調、logo、graphと本文の配置、範囲外の句読点は未達のままである。表の座標にも整数化とfontによる差が残り、原本全体の見た目の一致は承認していない。FontDescriptorのweight400やGothicという名前だけから太字と推定しない。
