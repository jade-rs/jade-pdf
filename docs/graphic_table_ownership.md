# 部分罫線と結合セルの所有

部分的な横線・縦線を持つ表では、同じ物理列で同じ横幅を持つセルだけを縦に結合する。接合部の形がL字やT字になる場合は、元の罫線を表現できる矩形に分ける。横結合の上下に部分罫線が残る範囲を一つの辺に潰さず、欠けた罫線を補わない。複数の接した線分でできた辺も、各小区間の被覆を確認して保持する。

縦結合した全物理行の文字を開始セルへ集める。継続セルの本文は空にし、元の表示行・基線・font size・書体・色を結合後の矩形全体から復元する。文字列の照合は各セルが所有する原本の矩形範囲で行い、同語の重複数も確認する。別セルへ値を移したモデルや、不正な継続関係は採用しない。Unicode正規化や別字への置換は照合に使わない。

この設計は、依頼された [kanpo-parser / kanpo-docx](https://github.com/bokuweb/lawrenceanum/tree/8322ad7895d8e15f7002c80e3f67c993edce99fd) の物理grid・一意なセル所有・矩形への分割の考え方を参考に、既存のIRとbuilderへ独立に実装した。参照先の独自Licenseのコードは転記していない。

所有されたgridのproperty testsでは、内部罫線を変えた64ケースと保存済みの失敗例について、全小区間の罫線、全列の被覆、結合関係、文字の所有を照合する。実資料ではBERTのFigure 5を表として扱っていた箇所から、不正な縦結合が判明した。結合の修正だけでは図の意味や描画を復元できない。グラフの色と曲線、表との判別、全ページの位置と改ページは引き続き検証する。
