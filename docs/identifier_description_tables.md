# 密なコード・説明表

短いコード名と説明が反復する罫線なし表を、独立した編集可能なWord行へ取り込む。従来は長い本文の誤認を防ぐガードで表の候補から除外され、左右の項目が別々の段落へ流れたり、原本の一ページが二ページへ増えたりしていた。

従来の表候補がないページで、同じ左右の原点を持つ6行以上の連続した対応だけを採用する。左列は空白のない短いASCII大文字コードで、少なくとも半数に数字またはunderscoreを含む。右列は通常語を含む複数語の説明を要求する。通常の二段組文章、大文字でも空白を持つ見出し列、重なる列、画像を含むページをこの経路へ昇格しない。一ページで採用する領域は一つであり、大文字と小文字が混在する識別子、複数行セル、一般的な本文の段組は対象外である。

コードの描画断片の境界へ空白を補わず、元の座標と明示的な空白からセル本文を復元する。説明の語間が独立した抽出要素でも保持する。コード自体に明示された空白を削除して候補を成立させない。run書式、列の原点差、原本の行間と最後の行のem高を使い、原本にない罫線を追加しない。領域が引き取る非空白文字も完全に照合する。

原本runの座標を確認した表には、旧表向けの上下原点の補正を適用しない。上半分の表へ下の注記を反転して含めることで、表全体が照合で拒否されたり注記が本文から除外されたりする問題を防ぐ。既存の罫線表などの補正経路は保持する。
