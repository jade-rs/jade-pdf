# 離れた枠のある表

罫線が各セルを独立した長方形として描く表では、閉じた枠が同じ列配置で3行以上反復するときに、元の位置から一つの編集可能な表を構成する。各辺を繋ぎ足して外枠にする処理は行わない。

- 物理gridには枠間の白い横・縦の帯も含める。空欄は削らず、元の幅と行高を保存する。
- 元の黒い実線がセルの一辺を完全に覆うときだけ、その辺を出力する。白帯を閉じたり、不完全な枠を補ったりしない。
- 文字の内容やsubstring検索で所属を決めず、元の矩形が一つの物理セルに収まる場合だけ対応させる。重複する値も別の位置の値として扱う。
- セル内の既知基線を使い、小さい指数の位置・font size・個別run styleを保持する。未知・曖昧な基線の位置は推測しない。

この経路は、ページの罫線が同一線幅の完全な独立長方形で構成され、行間が枠高以下で、各行に二つ以上の枠内値があり、各枠列に二行以上の値がある場合に限定する。部分罫線、非反復の枠、白い縦帯にある本文、セル境界を跨る文字、現行の整数point gridで表せない辺は従来の推定経路へ戻す。密な本文を拒否する既存のtext-grid閾値は変更しない。

`kanpo-parser` / `kanpo-docx` の、原本の物理gridを保ち、既存の辺の根拠から罫線を付け、文字の所属を曖昧にしない設計を参考にした。参照は [lawrenceanumの固定commit](https://github.com/bokuweb/lawrenceanum/tree/8322ad7895d8e15f7002c80e3f67c993edce99fd)。独自Licenseのコードは転記せず、このリポジトリのIRと既存builderに対して独立に実装している。

所有されたIRによる回帰とproperty testsは、4データ列（枠のない列を含む）、空欄、指数、paint順、同じ値の反復、白帯の罫線、曖昧な所有の拒否を検証する。これらは実資料全体の見た目を保証しない。塗り色、枠のないセルの正確な輪郭、セル内の字面の位置、ロゴ、改ページ、Wordでの描画は別に検証する。BIPM原本を含む公開資料の全体一致は未達である。
