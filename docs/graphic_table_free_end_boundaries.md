# グラフの自由端を表の列境界へ昇格しない

横罫線を横切る棒は、交点が多いだけでは表の列を示さない。従来は縦線が行帯を覆うだけで列候補へ追加し、実際の端点がセル隅へ接続しなくても部分罫線の表として受理していた。固定済みの労働力調査PDFでは、ベクターの棒が9行96列の架空の表になった。

## 限定した判定

内部列の候補になった縦線が、二つ以上の実在する内部横罫線を横切る場合に端点を確認する。推定枠の内部で止まり、その位置へ届く横線にも同一直線の継続にも接続しなければ、その罫線群から表を断定しない。文字は既存の段落経路へ残す。判定は線分の幾何だけを使い、原本の名前・語句・列数の上限で分岐しない。

横線のない見出し帯で止まる区切りや、複数の実在行を横切らない部分罫線は従来の表推定へ残す。横線との実際の接合、分割描画した同一直線の継続も許容する。水平棒・開いたグラフ・この交差条件を満たさない図形全般の識別は確認していない。公開field・CLI・依存の追加はない。

最初の広すぎる判定は暦と論文の実表にも影響したため、採用していない。元の試作・比較ログを保持し、条件を絞った後に、両資料を含む14件の既存出力がbyte一致へ戻ることを確認した。`open-header-scope-Red`という名の対照実行は実際には成功しており、失敗期待の指定ミスも保存し、製品不具合を再現したRedとして数えない。
