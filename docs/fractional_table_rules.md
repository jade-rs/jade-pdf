# 小数罫線の原本座標とWord表寸法

PDF罫線の小数ptを整数へ丸めると、原本99.5ptの列が100ptになり、細かい行高の差も失われる。parserは原本の有限な軸平行線座標を保持し、Word側はセル所有を決める従来の整数gridと、寸法を決める原本座標を分ける。

## 公開Rust APIの値の変更

`ParsedGraphicElement.bounds`の型・field・座標系は変えない。値は整数ptへ量子化した座標から、抽出時の小数ptを保つ座標へ変わる。近接していても固定軸の異なる平行線をparserで同じ線へ潰さないため、`ParsedDocument.graphics`の件数も変わり得る。同じ軸・ページ・固定座標の線分だけ、従来と同じ最大1ptの区間gapで結合する。NaN/無限座標は正規化前に除く。

整数を前提にした呼出元は、必要な箇所で明示的に`round()`して整数キーを作る。単なる`as i32`は小数の切り捨てとなり、従来の丸めと一致しない。配列長や整数castに依存する比較を見直す。生の原本値が必要な呼出元はそのままf32として利用できる。CLI、依存、公開structのfield追加はない。

## Wordへ適用する条件

Word側の表推定・行列・結合・文字所有は、既存の整数投影と結合を再構成したviewで行う。本文の挿入順、section原点、表を並べる判定、下線・footer書式にもこの互換viewを使う。原本座標をpublic IRで保持することだけを理由に、既存の本文配置を変更しない。

精密な寸法を適用するのは、同じページの表成分で各整数境界がただ一つの原本座標へ対応し、全区間を正のtwipとして表せる場合だけである。異なる平行線が同じ整数キーへ投影される場合、原本境界が欠ける場合、文字から補った境界やY反転が必要な表では従来寸法を使う。

全非空セルの原本文字と表示行を照合し、行が原本セル高に収まることも確認する。非空runのfontは、再利用可能な埋め込みfaceを確認できることを原則とする。狭い既知の例外はStandard14 Helveticaの単純な印刷可能ASCII、無変換のhalf-point文字高、通常weight、paintによる強調なしで、原本行の左右がセル内に収まる経路だけである。未埋め込みの日本語fontなど、未確認の代替字幅へ原本寸法を無条件に適用しない。条件を満たさなければ原本セル内の配置も整数gridで作り直す。

列幅と行高は累積した原本端点からtwipへ丸め、個別区間の丸め誤差を累積させない。Wordの寸法・セル内原点・表の上下配置は確認済みの原本gridを使うが、本文へ挿入する順番は従来の表矩形で固定する。論理行が増えた場合も物理的な原本gridと混同せず、対角罫線は元の四辺との対応が確認できる範囲で保存する。

## 厚労省の原本表と残る差

厚生労働省の「令和8年度 地域別最低賃金 全国一覧」を追加した。取得した一ページPDFと出典・利用条件・機密情報の確認、全原本ページの目視、69条件のgoldは初回の製品変換より先に固定した。49行5列と全1,474非空白文字、都道府県順、48組の新旧金額、太字の選択、灰色見出し、罫線座標を評価する。外部PDF・fontはローカル評価に保持し、tracked fixtureへ追加しない。

初回未知入力の結果は68/69であり、後の既知入力での追試と区別する。内罫線0.6ptと外罫線1.32ptがWordでは一律1.375ptになる条件は未達のままである。新旧金額の間隔にも目視差があり、69条件が厳密な字間全体を覆うとは主張しない。Microsoft Wordは未導入で実表示を検証していない。

## 回帰を採用しなかった経緯

小数境界を無条件に使った途中版では、本文の途中へ表が入り込む順序変更、最低賃金表の行境界の許容値超過、CPI描画後の文字在庫差、労働力調査のWord3ページから4ページへの増加を検出した。失敗したsource・実行ログ・出力・元のgoldを保持し、これらの版を適格版へ数えない。本文順序と原本寸法を分離し、font適合条件と互換viewを追加した。

官報の太字・罫線表を原本構造に沿って扱う方針は、[固定したkanpo-parser/kanpo-docxの参照](source_typography_and_table_opening.md#参照)を引き続き参考にした。custom licenseのコード・依存は取り込んでいない。
